# 🎮 Ping Pong – Java Game

Ein klassisches Ping-Pong-Spiel entwickelt in Java (Swing).  
Der linke Spieler wird **mit dem Mausrad** gesteuert, der rechte Spieler ist ein **Bot mit anpassbarer Schwierigkeit**.

## 🚀 Features

- 🖱️ **Mausrad-Steuerung** für den linken Schläger  
- 🤖 **Bot-Gegner** auf der rechten Seite  
- 🧠 Bot reagiert verzögert und ist schlagbar  
- ⚡ Dynamische Ballgeschwindigkeit mit Max-Limit  
- 🏁 Punktelimit (Standard: 5)  
- ⏸️ Pause-Funktion  
- 🏆 Game-Over-Screen  
- 🎛️ Startmenü  
- 🎨 Saubere Darstellung mit Mittellinie und Overlays  

## 🕹️ Steuerung

| Aktion | Taste |
|--------|--------|
| Spiel starten | **Leertaste** |
| Linker Schläger hoch | **Mausrad hoch** |
| Linker Schläger runter | **Mausrad runter** |
| Pause | **P** |
| Neustart | **R** |
| Beenden | **ESC** |

Der rechte Schläger wird automatisch vom Bot gesteuert.

## 📦 Installation & Start

1. Projekt klonen oder herunterladen  
2. Kompilieren  
3. Starten über:

bash

java GameFrame
